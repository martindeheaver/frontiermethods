# frontiermethods.com

Static website for Frontier Methods, served by GitHub Pages.

- `index.html` — the whole site (one page, no build step)
- `favicon.svg`, `apple-touch-icon.png`, `og-image.png` — icons and link preview image
- `assets/` — logo files (SVG and PNG, light and dark)
- `CNAME` — custom domain for GitHub Pages
